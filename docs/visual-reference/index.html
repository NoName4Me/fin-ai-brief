重点关注金融监管

资本市场AI治理强调全生命周期管理，应用边界与可信度评估受关注

上海证券报今日报道，证监会副主席刘浩凌在金融科技大会上提出，建立健全准入评估、动态监测、应急处置等全生命周期管理，探索符合我国资本市场实际的AI治理路径，科学划定高价值应用场景边界和风险容忍尺度。金融监管总局同时强调人在环路、数据网络安全与业务连续。相关内容为会议表态，尚不能等同于新增生效规则。

资管与基金

首批18只主动ETF拟明日开售，单只募集上限20亿元

据证券时报今日报道，首批18只主动ETF已披露招募说明书与发售安排，拟于10月23日开启发行，单只募集上限20亿元，部分产品募集期为5个工作日。披露的年管理费均为1%，托管费率为0.1%至0.15%。合计360亿元是募集上限，并非已经进入市场的资金。

证券时报 / 东方财富转载/01:17/
报告选读

日本央行贷款调查：企业需求DI由负转正，居民需求指标上升

日本央行发布10月大型银行信贷调查，覆盖50家银行，调查期为9月9日至10月13日。企业贷款需求DI为3，前次为－1；居民需求DI为5，前次为3；地方政府需求DI则由3降至－4。DI反映受访银行对需求强弱的判断，不代表贷款余额增速，也不宜直接外推为全部银行的信贷变化。

日本银行（BOJ）/07:50/
金融机构

29家全球系统重要性金融机构参会，讨论包容增长与金融治理

人民网今日报道，2026全球系统重要性金融机构会议于10月21日在北京举行，29家机构高级别代表参会，议题涉及金融赋能包容增长和金融治理革新。本条为今日披露的行业交流动态，报道未给出新的监管决定或具有约束力的共同协议。

人民网·北京频道/09:29/

AI要情

头部厂商 / 平台进展 / 技术研究 / 模型应用

本版4条
重点关注头部厂商与产业

OpenAI披露Google Cloud合作，模型与Codex将接入Model Garden

OpenAI宣布与Google Cloud合作，计划将其前沿模型和Codex智能体工作流引入Model Garden，为企业提供原生接入路径，结合Google Cloud的数据治理及基础设施能力。公告表达的是合作与后续集成方向，不能据此认定全部模型已向所有云客户普遍开放；具体可用范围仍须核对正式接入说明。

OpenAI 官方公告/03:23/
Claude平台进展

Claude API更新日期版本，升级SDK需留意不兼容变化

Anthropic发布2026-10-21版Claude API及配套SDK。迁移文档指出，新版请求不再接受temperature、top_p和top_k参数，部分消息结构与管理接口字段也需调整；旧版2023-06-01仍可使用。此次是接口版本与开发者工具变化，不是新的旗舰模型发布，已有集成应验证后再升级。

Anthropic 官方文档/05:03/
技术研究

Perplexity解读JOLT：让教师与学生共同训练，改善自蒸馏效率

Perplexity发布JOLT研究解读：同一策略分别扮演有额外信息的教师和无该信息的学生，并在训练中共同更新。作者报告，在MATH任务达到相同准确率时，JOLT使用的已处理训练token约为GRPO的1/6.5。这是论文设定下的实验结果，不能直接换算为通用训练成本下降；论文此前已上线，今天的进展是官方解读与传播。

Perplexity 官方研究博客/05:04/
模型与应用

HeyGen披露Video模型接入：一次调用生成画面与声音

HeyGen在官方说明中介绍其通用视频模型，支持文字、首帧图片或参考素材驱动，在一次调用中生成带声音的5至15秒短片，分辨率最高2K，并通过API提供。以上为厂商披露的能力与规格，本期未作实测，不将其写成独立验证的性能优势，也不认定这是模型首次上线。

HeyGen 官方产品说明/04:20/
