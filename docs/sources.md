### 关键接口与处理约定

- 金融监管总局使用官网脚本实际请求的 `https://www.nfra.gov.cn/cbircweb/DocInfo/SelectItemAndDocByItemUUId?pageSize=7&orderBy=item`；监管动态栏目915。详情为 `/cbircweb/DocInfo/SelectByDocId?docId=...`。也验证了官网对应的静态JSON路径；正式实现选一种，不增加双重请求。
- 证监会先由 `getLocalList?channelCode=c100028`确认真实栏目ID `a1a078ee0bc54721ab6b148884c784a8`，再请求其 `searchList`。不能把旧模板里的2021年静态列表当作最新资讯。`publishedTime`与 `publishedTimeStr`有8小时差异；另核对两篇详情，其PubDate也与列表时间不同，而且与页面生成时间相同。正式适配应先按原文确认的日期保存为日期精度，不把生成时间或有冲突的小时字段展示成发布时间。
- 银行保险报的官网接口为 `https://rm-api.cfmc.cn/web/home/news` 和 `/web/news/getDetail`，POST表单字段 `data` 为JSON字符串；请求带官网公开的站点标识 `tenantId:37`，不使用登录凭据。详情请求示例为 `data={"news_id":"334936"}`。未传站点标识会返回“租户不存在或已关闭”，已验证正确参数可直接取得内容。
- 上证报和财联社的相关页面有 `__NEXT_DATA__` JSON，详情提供绝对时间，列表的“几分钟前”不作为入库时间。上证报需区分普通文章、专题、广告及跳转链接；实际原始来源单独保留。
- 只摘取简短摘要及原文链接，不存第三方全文；研究时取得的原始响应保存在忽略提交的 `.data/source-check/`。

### 筛选建议

优先组合：央行 + 金融监管总局 + 证监会提供一手政策，上证报金融频道补基金和资本市场，中国银行保险报补银行保险机构业务。若重视金融科技，可加移动支付网；若重视快讯速度，再补财联社大金融。证券时报先作为上证报的补充，避免两家综合财经媒体同时全量采集。

内容筛选按事实和栏目相关性，不按文章数量。监管材料中也有会议、行政任职和招考通知；媒体材料里有企业宣传和产品营销，都要筛选。读到内容不等于所有条目都应入选。

金融核查证据保存在 `.data/source-check/finance-verification.json`、`finance-extra-verification.json` 及对应原始响应；记录有样本标题、链接、时间、可取得的内容字段。本次只启用用户确认的前五家，不自动加入其余补充来源。

## 机器之心免费RSS限频与令牌

访问令牌保存于本地 `.env` 的 `JIQIZHIXIN_RSS_TOKEN`，不进入数据库订阅地址、仓库或公开页面。请求只在服务端发往指定的官方HTTPS RSS端点时附加令牌。管理页只显示是否配置。至少60分钟一次，常规运行24小时最多约24次；手动触发同样受限，失败请求也等待下一轮，不自动重试。首次接入排错复查收到429，下一轮按既定间隔再验证；当前不能宣称已完成真实入库。RSS未提供摘要时只保留现有标题，不读取数据服务引导页来拼接“摘要”。

## 已上线的适配细节

`finance-sources.ts`负责五家已确认来源的字段映射、日期精度、栏目选择和摘要提取；不新增媒体品牌格式。请求仍经过相同的地址校验、响应大小约束和限流处理。

上证报网页详情对应用请求返回防护页，因此生产适配使用其官网移动端使用的公开 `https://api.cnstock.com/wap/news/newsDetails`，POST JSON `{contId:文章ID}`，公开客户端标识 `cnstock-client-type:02`，无需登录或凭据。只选择金融频道普通文章，保留原文链接和原始来源，不模拟浏览器或维护防护Cookie。

银行保险报使用金融监管、银行、保险、资管非银、农村金融、金融科技这六个栏目，不采首页综合、视频、金融文化等栏目。选择普通文章，排除视频等格式。监管总局不采总局机关任职批复栏目。重复条目在读取详情前查重，只存最多1200字的来源摘要，不存第三方页面全文。
